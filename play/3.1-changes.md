## 3.0 대비 변경
- 클랜: 개발자 승인 단계 삭제(자동 노출), 노출 15일, 완전 무료(유료 모드 없음), 대기열은 등록 순서대로 자동 시작
- 자동 방어: 글자 수 제한, 링크·금칙어 검사, 중복 이름/링크/폰 차단, 하루 등록 한도, 서로 다른 폰 3대 신고 시 자동 숨김
- 구글 시트 스크립트(tools/clan-server.gs) 교체 필요 — 웹앱 주소는 그대로
- 라이브러리: Play가 지적한 androidx.fragment 1.0.0 → 1.8.9로 고정, 빌드 도구(AGP 8.13.2/Gradle 8.14.3/Kotlin 2.1.21) 최신화, targetSdk 36 유지(동작 변화 없음)
- 새 기능: 시즌 종료 D-7/D-1 알림(비정확 알람, 알림 채널 '시즌 종료 알림'), 설정 백업·복원(공유창으로 보내고 클립보드에서 복원, 소리 설정은 제외)

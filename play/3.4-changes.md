# 3.4 (versionCode 56) — 출시 노트 (플레이 콘솔 '이 버전의 새로운 기능'에 붙여넣기)

<ko-KR>
- 알람 버튼을 [끄기](지금 울리는 알람만) · [이번 회만](이번 회 남은 알림 모두) · [알람 해제](그 알림을 아예 끔)로 정리했어요. 잠금 화면과 알림 팝업 모두 같아요.
- [알람 해제]는 한 번 더 물어보고, 해제한 뒤에는 [다시 켜기] 알림이 남아요. 3일 동안 꺼져 있으면 한 번만 알려드려요.
- 홈에서 꺼진 알림 줄을 누르면 바로 다시 켜져요.
</ko-KR>

## 3.3 대비 변경
- AlarmActivity/알림 버튼: [다음 회까지] 삭제 → [알람 해제] 추가 (알림 왼쪽부터 알람 해제 / 이번 회만 / 끄기)
- ACTION_DISABLE: 해당 이벤트 on=false(설정 유지), 예약 취소, 꺼짐 안내 알림 / ACTION_ENABLE: 다시 켜기
- OffReminder: 꺼진 지 3일 후 1회 조용한 알림 (비정확 알람, 소리 없음)
- 홈: 꺼진 줄 탭 = 바로 켜기, 알람 화면에 버튼 설명 한 줄

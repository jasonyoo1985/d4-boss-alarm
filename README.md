# 디아4 월드보스 알람

디아블로4 월드보스 출현 일정 및 알림 앱. 지옥물결과 군단 시간도 함께 알려줍니다.
서버 없이 고정 주기로 계산하기 때문에 외부 사이트가 멈춰도 동작합니다.

| 이벤트 | 주기 | 진행 시간 |
| --- | --- | --- |
| 월드보스 | 3시간 30분 | 약 15분 |
| 지옥물결 | 매시 정각 | 55분 |
| 군단 | 25분 | 약 4분 |

기준 시각은 `app/src/main/java/com/jaewook/d4timer/Schedule.kt`에 있습니다.
블리자드가 주기를 바꾸면 이 파일만 고치면 됩니다.

## 구조

화면은 `app/src/main/assets/index.html` 웹 페이지이고, `MainActivity.kt`가 알람·벨소리·권한을 연결합니다.
이벤트마다 폰에 있는 벨소리를 알람음으로 고를 수 있습니다.

## 설치

`main`에 푸시할 때마다 GitHub Actions가 APK를 빌드해서 **Releases → 최신 버전**에 올립니다.
폰에서 `d4-boss-alarm.apk`를 받아 설치하세요. 처음 한 번은 "출처를 알 수 없는 앱 설치"를 허용해야 합니다.

`app/debug.keystore`는 직접 설치용 서명 키입니다. 플레이스토어에 올릴 때는 별도의 업로드 키를 써야 합니다.

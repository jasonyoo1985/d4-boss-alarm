# 성역 이벤트 타이머

디아블로4 월드보스, 지옥물결, 군단 시작 시간을 보여주고 알림을 보내는 안드로이드 앱입니다.
서버 없이 고정 주기로 계산하기 때문에 외부 사이트가 멈춰도 동작합니다.

| 이벤트 | 주기 | 진행 시간 |
| --- | --- | --- |
| 월드보스 | 3시간 30분 | 약 15분 |
| 지옥물결 | 매시 정각 | 55분 |
| 군단 | 25분 | 약 4분 |

기준 시각은 `app/src/main/java/com/jaewook/d4timer/Schedule.kt`에 있습니다.
블리자드가 주기를 바꾸면 이 파일만 고치면 됩니다.

## 설치

`main`에 푸시할 때마다 GitHub Actions가 APK를 빌드해서 **Releases → 최신 버전**에 올립니다.
폰에서 `sanctuary-timer.apk`를 받아 설치하세요. 처음 한 번은 "출처를 알 수 없는 앱 설치"를 허용해야 합니다.

`app/debug.keystore`는 직접 설치용 서명 키입니다. 플레이스토어에 올릴 때는 별도의 업로드 키를 써야 합니다.
